# Verification Register

**Every fact the framework needs but hasn't yet confirmed.** Nothing on this list goes into an ad until it's verified and moved to the relevant product file with its source.

**How to verify:** photograph the current pack (front, back, nutrition panel), and file lab reports and regulatory advice in a shared folder. Record the source and date below.

| Status | Meaning |
|---|---|
| ⬜ | Not verified |
| ✅ | Verified: source recorded |
| ❌ | Verified as false: remove from all copy |
