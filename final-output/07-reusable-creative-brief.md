# Reusable Creative Brief

The full template, with field-by-field guidance and a filled example, is in **[`10-creative-brief-template.md`](../10-creative-brief-template.md)**.

Below is the **quick version**, for a first pass or a fast static brief. Upgrade to the full template before a video shoot.

```markdown
# QUICK BRIEF — [Concept name]

Product:           [one product]
Audience:          [specific person + situation]
Consumer tension:  [T-## + customer's words]
Current behaviour: [what they do now]
Old solution:      [generic alternative, never a brand]
Insight:           [one sentence]
Belief shift:      FROM "[ ]" → TO "[ ]"
Route:             A Craving / B Label / C Routine / D Humour
Hook:              [exact words]  (category: )
Mechanism:         [verified swaps only]
Proof:             [what we SHOW]
Objection:         [ ] → answer: [ ]
Visual:            [setting, props, light, mood]
Scene 1 (Hook):    [ ]
Scene 2 (Tension): [ ]
Scene 3 (Swap + Pack + Back-of-pack): [ ]
Scene 4 (Taste + CTA): [ ]
CTA:               [ ]
Variants:          3 hooks (different categories) · 2 first frames · 2 lengths ·
                   2 CTAs · 1 static adaptation
Success criteria:  [primary metric vs control/baseline] · kill if [ ]
Claims check:      [each claim → green/yellow + source]
```

**Stop / Care / Believe / Act check** (answer before approving the brief):
- **Stop:** Why would *this* person stop? ______
- **Care:** Why would they care? ______
- **Believe:** Why would they believe us? ______
- **Act:** Why would they act *now*? ______
